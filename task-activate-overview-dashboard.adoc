= Workload Factory for EDAで概要ダッシュボードをアクティブ化する
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
概要ダッシュボードをアクティブ化して、FSx for ONTAP ファイルシステムの CloudWatch メトリクスの収集を開始します。ダッシュボードでは、クラスターの状態、容量、スループットを1か所で確認できます。



[[before-you-begin]]
== 開始する前に

ダッシュボードを有効化する前に、以下の要件を満たしていることを確認してください。



[[aws-credentials-with-view-permissions]]
=== 表示権限を持つ AWS クレデンシャル

Workload FactoryでAWS認証情報を設定する際には、General Storageに対して少なくとも読み取り（表示）権限を付与する必要があります。_Basic_認証情報はサポートされていません。

閲覧権限を持つ認証情報を設定していない場合は、「概要」タブを開いたときにAWS認証情報設定ページにリダイレクトされます。

AWS 認証情報をまだ設定していない場合は、link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["AWS認証情報を追加する"^]を参照してください。



[[activate-the-dashboard]]
== ダッシュボードをアクティブ化する

Workload Factory が閲覧権限を持つ認証情報を検証した後、ダッシュボードをアクティブ化して、FSx for ONTAP ファイルシステムの CloudWatch メトリクスの収集を開始します。


NOTE: 同意いただいた後、指標の収集には少々時間がかかる場合があります。ダッシュボードは、最初の収集が進行中であることを通知します。

.手順
. 次のいずれかを使用してログインします link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["コンソール体験"^]。
. メニューimage:workloads-menu-icon.png["ハンバーガーメニューアイコン"]を選択し、*EDA*を選択します。
. * Overview *タブを選択します。
. 表示権限を持つ認証情報が検出されない場合は、*認証情報の追加*を選択し、プロンプトに従って表示権限を持つ AWS 認証情報を設定します。次に、*概要*タブに戻ります。
. FSx for ONTAP ファイルシステムに対して収集される CloudWatch メトリクスについて説明している同意プロンプトを確認します。
. ダッシュボードをアクティブ化し、メトリックの収集を開始するには、* Activate * を選択します。


.結果
Workload Factory は、AWS 認証情報にリンクされているすべての FSx for ONTAP ファイルシステムの CloudWatch メトリクスの収集を開始します。メトリクスが利用可能になると、ダッシュボードに反映されます。データ収集が進行中の間は、通知が表示されます。



[[next-steps]]
== 次の手順

ダッシュボードを有効化すると、以下の操作が可能になります：

* link:task-use-overview-dashboard.html["概要ダッシュボードを使用する"]クラスタの健全性と容量を監視
* SSD容量管理モード（Automate、Recommend、またはNone）を設定します。
* 特定のリージョンまたはAWSアカウントに絞り込むためのフィルターを設定します
