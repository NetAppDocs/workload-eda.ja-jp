= EDA向けワークロードファクトリについて学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Workload Factory for EDA は、複数のファイルシステムにわたって FSx for ONTAPを最適化するのに役立ちます。ストレージ パラメータを自動化し、パフォーマンス制約を分析し、EDA プロジェクトに関する分析情報を取得することで、パフォーマンスを最適化し、運用コストを削減できます。

これは、Infrastructure as Code (IaC) フレームワークと統合するように設計されています。

Workload Factory for EDA は、複数の FSx for ONTAPファイル システムの管理に役立つダッシュボード、ストレージ自動化フレームワーク、ユーティリティを提供します。

以下の機能を提供します:

* link:task-use-overview-dashboard.html["概要ダッシュボード"]：FSx for ONTAP クラスターの健全性、容量、スループットを監視し、新しいボリュームを配置する場所を決定し、容量とスループットの拡張について情報に基づいた意思決定を行い、自動化された容量推奨事項を受け取るのに役立つ集中型クラスタ ビューを提供します。
* link:task-configure-dashboard.html["プロジェクトダッシュボード"]：FSx for ONTAPファイルシステム全体のストレージ消費量を一元的に表示し、プロジェクト全体のストレージ使用状況に関する計画、コストの評価、情報の収集を支援します。
* link:task-monitor-latency.html["ボリュームのレイテンシを監視する"]：ボリュームの読み取りおよび書き込みレイテンシのパフォーマンスを、設定可能な警告および重大イベントのしきい値を使用してプロアクティブに監視します。イベントが検出された際に、メールまたはSNS通知を受け取ることができます。ONTAP QoS遅延センターの指標を使用した自動基本分析と、より詳細な根本原因の特定が必要な複雑なシナリオ向けのオプションのAIエージェント分析が含まれます。
* link:task-analyze-latency-trends.html["レイテンシの傾向を分析"]：インタラクティブなレイテンシーグラフを使用して、時間の経過に伴うレイテンシーの動作を視覚化し、パターンを特定し、パフォーマンスの問題が繰り返し発生しているか単発的であるかを理解し、修復に関するデータ主体の決定を行います。
* link:learn-eda-workloads.html["CI/CD"]: FSx for ONTAPボリューム クローン機能を活用して、ソフトウェアのビルド時間を効率化し、短縮します。
