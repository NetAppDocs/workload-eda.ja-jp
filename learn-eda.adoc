= EDA向けワークロードファクトリについて学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Workload Factory for EDA は、複数のファイルシステムにまたがって Amazon FSx for ONTAP を管理するのに役立ちます。ストレージ設定の自動調整、レイテンシーの問題の検出、EDA プロジェクトに関するインサイトの提供により、パフォーマンスを向上させ、コストを削減します。

これは、Infrastructure as Code (IaC) フレームワークと統合するように設計されています。

Workload Factory for EDA は、複数の FSx for ONTAP ファイルシステムを管理するのに役立つダッシュボード、自動化ツール、ユーティリティを提供します。

以下の機能を提供します:

* link:learn-overview-dashboard.html["概要ダッシュボード"]：FSx for ONTAP クラスターの単一ビューを提供し、健全性、容量、スループットを監視できます。これを使用して、新しいボリュームをどこに配置するかを決定したり、容量やスループットを増やすタイミングを計画したり、自動的な容量推奨事項を取得したり、自動スケーリングを有効にしたりできます。過去の決定事項を確認することで、システムの推奨事項が時間の経過とともにどのように変化してきたかを知ることもできます。
* link:learn-latency-monitoring.html["ボリュームのレイテンシを監視する"]：ボリュームの読み書きレイテンシを監視し、警告およびクリティカルのしきい値を設定できます。しきい値を超えると、メールまたは SNS で通知を送信します。ONTAP QoS 遅延センターメトリクスを使用した自動基本分析が含まれており、より深い根本原因の特定が必要な複雑な問題に対しては、オプションで AI 分析も利用できます。
* link:task-analyze-latency-trends.html["レイテンシの傾向を分析"]：レイテンシ、IOPS、スループットの同期されたパフォーマンスグラフを使用して、これらの指標が時間の経過とともにどのように変化するかを確認します。これは、パターンを把握し、問題が繰り返し発生するのか、それとも一度きりなのかを判断し、解決策について十分な情報に基づいた意思決定を行うのに役立ちます。
* link:learn-project-dashboard.html["プロジェクトダッシュボード"]：すべての FSx for ONTAP ファイルシステムのストレージ使用量を1か所に表示することで、容量計画、コスト見積もり、各プロジェクトにおけるストレージ使用状況の把握に役立ちます。
* link:learn-eda-workloads.html["CI/CD"]：FSx for ONTAP ボリュームを迅速にクローニングすることで、ソフトウェアビルドを高速化します。
