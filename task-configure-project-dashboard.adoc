= Workload Factory for EDA でプロジェクトダッシュボードを設定します。
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
プロジェクトダッシュボードでカスタムフィルターを設定することで、プロジェクト別、チーム別、コストセンター別など、ビジネスの仕組みに合わせてデータを整理できます。これにより、コストを明確に把握しやすくなり、どのリソースが最も多くのキャパシティを消費しているかを特定し、予算や人員配置についてより適切な意思決定を行うことができます。フィルターが組織構造に合致していれば、必要なデータを迅速に見つけることができ、キャパシティ、コスト、パフォーマンスをより効率的に管理できます。



[[before-you-begin]]
== 開始する前に

カスタムフィルターを使用するには、プロジェクト、チーム、事業部門などのニーズに応じたタグを FSx for ONTAP ボリュームに AWS タグとして追加してください。



[[configure-custom-filters]]
== カスタムフィルターを設定する


NOTE: プロジェクトダッシュボードを最初に開いた管理者のみが、カスタムフィルターを作成、変更、または削除できます。他の管理者を含むすべてのユーザーは、フィルターを表示することのみできます。

.タスク概要
AWSタグを使用して、最大5つのカスタムフィルターを設定できます。各フィルターには、フィルターラベル、AWSタグキー、および選択タイプ（単一または複数）が必要です。

カスタムフィルターを設定しない場合でも、デフォルトのフィルター（ファイルシステム、ボリュームタイプ、時間範囲）は引き続き利用できるため、ダッシュボードの表示と使用を継続できます。

.手順
. 次のいずれかを使用してログインします link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["コンソール体験"^]。
. メニューを選択 image:workloads-menu-icon.png["ハンバーガー メニュー アイコンは、ストレージ、eda、ai、データベース、vmware、管理などのワークロードに移動するために使用されます。"] 次に*EDA*を選択します。
. *Projects* を選択します。
+
ダッシュボードをまだ構成していない場合は、自動的に構成するように求められます。

. *+ フィルターを追加*を選択します。
. 作成するカスタムフィルタごとに、詳細を追加します。
+
** フィルターラベル名（ダッシュボードでの表示名）
** AWSタグキー名（リソースで実際に使用されるタグキー）
** 選択タイプ（単一選択または複数選択）
+

NOTE: フィルターは、設定した順序でダッシュボードに表示されます。よく使うフィルターは一番上に配置しておくと、アクセスしやすくなります。



. *適用*を選択します。
+
変更を適用する前に、そのフィルターの横にあるゴミ箱アイコンを選択すると、カスタム フィルターを削除できます。

. タグやフィルターを適用した後の変更内容を確認するには、ダッシュボードの更新アイコンを選択してください。
. 後でダッシュボードの設定を編集するには、[設定] を選択します。


.結果
これらのタグを適用すると、Workload Factory は関連する CloudWatch メトリクスの収集と表示を開始します。ダッシュボードを使用すると、リソースの整理、コストの追跡、ニーズに基づいたアイテムのフィルタリングが可能になります。
